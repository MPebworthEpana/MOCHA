# Extract the GRanges for a particular cell population

`getCellTypeTiles` Returns a GRanges object of all tiles called for a
certain cell type

## Usage

``` r
getCellTypeTiles(object, cellType)
```

## Arguments

- object:

  A SampleTileObject.

- cellType:

  A string describing one cell type.

## Value

a vector of cell type names.
