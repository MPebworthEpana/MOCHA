# Add InsertionBias to MOCHA object

Generated and Add InsertionBias to MOCHA object

## Usage

``` r
addInsertionBias(SampleTileObj, numCores = 1, verbose = TRUE)
```

## Arguments

- SampleTileObj:

  A Sample-tile object from MOCHA's getSampleTileMatrix()

- numCores:

  Number of cores to parallelize oer

- verbose:

  A boolean to determin

## Value

A Sample-Tile object with an insertion bias matrix within the metadata
list
