# exampleBlackList

Example input of a blackList extracted from the PBMC_Small dataset
consisting of 2k cells and spanning chr1 and 2 (~2-300MB). The data is
publicly available with the ArchR package at
\<https://www.archrproject.com/reference/getTestProject.html\>

## Usage

``` r
exampleBlackList
```

## Format

A GRanges object with 210 ranges and 2 metadata columns
