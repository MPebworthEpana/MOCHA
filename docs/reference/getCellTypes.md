# Extract cell population names from a Tile Results or Sample Tile object.

`getCellTypes` Returns a vector of cell names from a Tile Results or
Sample Tile object.

## Usage

``` r
getCellTypes(object)
```

## Arguments

- object:

  tileResults object from callOpenTiles or SummarizedExperiment from
  getSampleTileMatrix

## Value

a vector of cell type names.
